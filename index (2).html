About me

I'm a third-year Applications Development student at the Cape Peninsula University of Technology. I build software across the whole stack: the database design, the API behind it, and the screens people actually use. My work so far includes a client-server enrolment system in Java, an e-commerce site on PHP and MySQL, and PulseUp, a clinic booking platform built with React and Spring Boot.

Since September I have also been a Digital Associate in CAPACITI's Data Academy, a 12-month programme where I work in teams to build AI-powered products: a farming chatbot, a content generator, a sentiment analysis tool and a civic reporting app. I care about getting the fundamentals right, from clean database design to secure sign-in, and about interfaces that are clear to the people using them.

What I've learned

A login error should never say which emails exist.

Building PulseUp's sign-in taught me the difference between not knowing who you are (401) and knowing you but saying no (403). Checks in the browser only help the user. The server has to repeat every one of them.

Getting a team's code to run is half the job.

I fixed compile errors, set environment variables, generated a secret key, and traced blocked requests to a dev server that had moved to another port. Now I write down how to run a project as I go.

AI is only as good as the app around it.

CivicFix lets the resident confirm or change the AI's suggestion instead of trusting it blindly. That is the kind of software I want to build: useful, and clear about what it is unsure of.
